# AGENTS.md

Guía para agentes que trabajen en este repositorio (sitio Jekyll de Casa Faro).

Para la arquitectura, comandos y estructura del proyecto, consulta `CLAUDE.md`.

## Lenguaje inclusivo (obligatorio)

Todo el copy del sitio debe evitar el **masculino genérico** al referirse a personas o
grupos de personas (mixtos o de género no especificado). Esto aplica a **todo** el texto
visible y a los datos que lo alimentan: `index.md`, `about/`, `ourwork/`, `contact/`,
`recursos/`, `_data/*.yml`, `_includes/`, `_layouts/`, `_config.yml` y `404.html`.

Reglas:

- Nunca uses "los", "los que", "todos", "unos", "algunos", "aquellos", "nosotros como
  grupo", ni sustantivos en masculino plural para referirte a personas.
- Prefiere formas neutras: "quienes", "las personas", "el personal", "el equipo", "la
  ciudadanía", "el alumnado", "cada persona", etc.
- Para cargos o colectivos concretos usa el artículo/femenino que corresponda a la
  persona real (p. ej. "Directora", "Director") solo cuando se refiera a alguien específico.
- Revisa también títulos, botones, enlaces de navegación, pies de página y metadatos.

Ejemplos de reescritura:

- "Cuidamos a **los que** cuidan" → "Cuidamos a **quienes** cuidan"
- "Bienvenidos" → "Bienvenidas personas" / "Te damos la bienvenida"
- "Los profesionales deben…" → "El personal profesional debe…" / "Quienes ejercen la
  profesión deben…"
- "Todos los usuarios" → "Todas las personas usuarias" / "Quienes usan el sitio"
- "Acompañamos a los colaboradores" → "Acompañamos al equipo" / "a las personas
  colaboradoras"

Antes de dar por terminado un cambio de contenido, revisa el texto buscando masculinos
genéricos y corrígelos.
